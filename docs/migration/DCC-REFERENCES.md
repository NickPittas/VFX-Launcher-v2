# Native DCC workspace references

These references support the user's authoritative DCC desktop direction in
USER-UI-REQUIREMENTS.md. They replace the earlier dashboard composition.

## Inspected visual references

- `artifacts/design-references/maya-classic-interface.png`: Autodesk's annotated
  Maya Classic interface. Actual full interface screenshot inspected. Source:
  https://help.autodesk.com/cloudhelp/2022/ENU/Maya-Basics/files/GUID-F4FCE554-1FA5-447A-8835-63EB43D2690B.htm
  Visual cues: continuous tiled workspace, compact menu/tool rows, narrow panel
  headers, thin split boundaries, rectangular controls, docked properties and
  bottom status/feedback. It is a historical screenshot, not current-version QA.
- `artifacts/design-references/nuke-pane-menu.png`: Foundry's pane context menu.
  Actual image inspected; this is a pane-menu detail, not a full Nuke screenshot.
  Source: https://learn.foundry.com/nuke/content/getting_started/using_interface/using_compositing_env.html
  Cues: compact rectangular pane chrome, split/dock/tab actions, contextual
  controls attached to their working area.

Foundry's workspace documentation describes resizable/splittable panes:
https://learn.foundry.com/nuke/9.0/content/getting_started/using_interface/workspaces.html

## Apply to Launcher

One bounded application window. Compact menu bar and workspace selectors.
Working dock panes fill the window; no tall website sidebar with brand padding,
floating rounded cards, page headings or page-length content stacks. Equal-height
adjacent trees/tables with independent internal scrollbars, narrow horizontal and
vertical splitters, lower destination-preview dock, visible bottom execution and
status strip. Keep clear labels and the user's blue first-step Scan folders
control. This is an interpretation of the references for this utility, not a
pixel-for-pixel clone or permission to add DCC features.
