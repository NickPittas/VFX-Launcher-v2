# Projects

[All guides](../README.md) · [Downloads](../../README.md#downloads)

1. Click Add existing folder… to register a folder without creating a new project structure. Use New project… when you want to create folders from a template.
2. Click Scan folders and wait for completion; inspect folder details and any errors. Cancel scan stops an active scan.
3. Select a project on the left. Use All, Favorites or Recent and the project filter to narrow the list.
4. Switch between Nuke and After Effects, filter the file list, and choose the desired version where a version selector is shown.
5. Click Launch. The corresponding executable must be configured in Settings and installed on the host.

Right-click projects for favorites, folder-path copying, information and Unregister project (keep files). Unregister removes the catalog entry while retaining files. File context menus provide path and information actions and available launch/reveal actions. A launch request being accepted does not prove that the external application loaded the document.

If nothing appears, select a project, check the chosen file type and filters, and rescan its configured folders. Check Settings and history for launch errors. Linux file reveal requires host `gdbus` and a file manager implementing FileManager1; failures are reported.
