# Shots & Sequences

[All guides](../README.md) · [Downloads](../../README.md#downloads)

Create a project from Projects → New project…. Choose Create inside, naming format, number/client/name/date as applicable, and a Folder template. Review the resulting Project folder name and destination before creation. Configure frame rate and resolution where offered, and define the initial sequences and shots.

Use Manage… beside the template selector to administer templates, folders and client names. Changes affect future generated structures; review the preview after editing a template.

For an existing registered project:

1. Select the intended project and open Shots & Sequences.
2. Review the current destination tree and choose the destination for the new structure.
3. Add the required sequences and shots, or standalone shots.
4. Use Regenerate preview and inspect the proposed folders/files and reported conflicts.
5. Review/validate using the available controls, then choose Add to project when enabled.
6. Read the completion report and rescan Projects to discover newly created scripts.

Correct invalid names, unavailable roots or conflicts before proceeding. A preview is a proposal; creation is the explicit execution step. Do not assume an existing folder was overwritten when the report says skipped or blocked.
