# Settings

[All guides](../README.md) · [Downloads](../../README.md#downloads)

Configure Nuke and After Effects executable paths for launching project files. Configure DJV, MRV2 and Nuke Player paths for Incoming context actions where available. Linux also offers an optional Nuke launch command. These applications are external installations.

1. Edit paths directly or use Browse….
2. Click Save and wait for the saved confirmation. A click alone does not establish that the write succeeded.
3. Use Cancel to discard unsaved edits. Read validation errors before retrying.

Manage user attribution in the users section. Select the current user on Projects. User names identify recorded actions; they are not provider credentials. Follow the displayed restrictions when editing or deleting users.

Expand Import previous Launcher data to select and review legacy sources. Inspect the proposed import and its errors before adopting it. Keep a backup of legacy data; the Rust application does not automatically switch to an existing Python database.

Expand Data location to see the current local data area and any settings-load error. For a separate catalog/configuration, start with `--data-dir` as documented in your platform guide. Logs opens the shared logs and file-operation history window.

Pi suggestions use an external harness for provider authentication. Review the Incoming suggestion context before submission; do not store provider secrets in project media or prompts.
