# Copy by File Type

[All guides](../README.md) · [Downloads](../../README.md#downloads)

1. Choose Source folder and Destination folder.
2. Add the required extensions under File types; remove unwanted extension chips. Set exclusions and Copy workers as appropriate.
3. Choose the Existing files policy and click Scan folders.
4. Review Files to copy, select the intended entries and inspect preserved relative destination paths.
5. Click Validate selection. Read refusal details before changing roots or policies.
6. Click Copy selected when enabled. Follow progress, then inspect each file result.

Changing roots, policy or selection invalidates older approval. Current validation failures appear above historical results; a Previous run report describes an older selection. Hover over a shortened current-file label to see its full path.

Contained links to files are copied from their captured targets in the newer Linux releases while keeping the selected destination name. Outside-root links remain refused. A source-drive continuity advisory alone does not prohibit copying; inspect the actual blocking reason. The feature-local link checks do not establish SMB/NAS parity.
