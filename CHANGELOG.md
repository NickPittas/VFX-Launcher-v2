# Release history

## 0.3.4 — 2026-11-06 · Linux and Windows

Newer ARRI filenames, extension keywords such as `.cube`, Incoming resolution reads, robust ffprobe JSON parsing and explicit Pi model discovery/submission. Includes the 0.3.3 fixes. Windows is built natively on kamino-3; the file-manager reveal fix is Linux-specific. [Full notes and verification limits](docs/RELEASE-0.3.4.md).

## 0.3.3 — Linux fixes included in 0.3.4

Linux file-manager reveal, visible validation failures and approval invalidation. No separate GitHub release was published. [Details](docs/RELEASE-0.3.3.md).

## 0.3.2 — 2026-11-06 · Linux

Stable one-line current-file progress labels in copy and backup, with full paths on hover. [Details](docs/RELEASE-0.3.2.md).

## 0.3.1 — 2026-11-06 · Linux

Contained file-link copying, accessible execution controls, actual refusal reasons and consolidated advisories. [Details and local verification](docs/RELEASE-0.3.1.md).

## 0.3.0 — 2026-11-06 · Linux

Incoming media/sequence preview, external players, Nuke socket actions, bounded Python-style regex support and migration/settings/history corrections. [Details](docs/RELEASE-0.3.0.md).

## 0.2.0 — 2026-11-06 · Linux and Windows prerelease

Native desktop with project scanning/version selection, structure creation, Incoming, file-type copying and backup. The Windows portable ZIP and checksum are published on [GitHub](https://github.com/NickPittas/VFX-Launcher-v2/releases/tag/v0.2.0). [Release packet](docs/RELEASE-0.2.0.md) · [Windows installation and limitations](docs/WINDOWS.md).

The Python application's historical 1.x releases use a different version line. The Rust 0.x packages are the migration desktop. Release numbers do not establish complete legacy parity or production/NAS verification.
